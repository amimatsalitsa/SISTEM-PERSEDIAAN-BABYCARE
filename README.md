## 📖 Tentang Proyek

**Sistem Persediaan BabyCare** adalah aplikasi web sederhana yang dirancang untuk mengelola data persediaan produk *baby care* secara efisien. Aplikasi ini dibangun menggunakan **HTML, CSS, dan JavaScript murni** (tanpa framework frontend) serta memanfaatkan **Supabase** sebagai backend database melalui REST API.

Proyek ini dibuat untuk memenuhi tugas mata kuliah **Pengkodean dan Pemrograman** sekaligus sebagai implementasi nyata dari konsep sistem informasi akuntansi, khususnya dalam pencatatan dan pengelolaan persediaan barang.

---

## ✨ Fitur Utama

- 📦 **Manajemen Produk** — Tambah, lihat, dan kelola data produk baby care.
- 📊 **Monitoring Stok** — Pantau ketersediaan stok secara real-time.
- 🔐 **Koneksi Supabase** — Konfigurasi Project URL & publishable key langsung dari halaman **Pengaturan**.
- ⚡ **Tanpa Build Tool** — Cukup buka `index.html` di browser, tanpa perlu instalasi package.
- 🎨 **UI Ramah Pengguna** — Tampilan lembut dan bersih, cocok dengan tema *baby care*.
